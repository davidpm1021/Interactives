What gets calculated: When you enter Hours and Rate, the current and YTD amounts compute automatically. Social Security ({{ SOCIAL_SECURITY_RATE | percent: '1.1-2' }}) and Medicare ({{ MEDICARE_RATE | percent: '1.2-2' }}) are computed from gross pay. YTD totals everywhere multiply the current amount by the number of pay periods completed this year. The rest (federal tax, state tax, deductions) is whatever you type in.
